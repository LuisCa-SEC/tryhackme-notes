# Networking Basics

## Topics Learned
- IP Addresses
- Public vs Private Networks
- Ports and Protocols
- TCP vs UDP
- DNS
- HTTP and HTTPS
- OSI Model Basics

## Important Ports
| Port | Protocol | Purpose |
|------|------|------|
| 80 | HTTP | Web traffic |
| 443 | HTTPS | Secure web traffic |
| 22 | SSH | Remote secure access |
| 53 | DNS | Domain name resolution |

## Key Concepts
- Devices communicate through IP addresses.
- Ports help identify specific services.
- DNS translates domain names into IP addresses.
- HTTPS encrypts web traffic for security.

## Notes
Networking fundamentals are essential for cybersecurity, SOC operations, and cloud security.
