# Hawks Academy - Cyber01

## Course Overview
Introduction to cybersecurity concepts, defensive security, networking, operating systems, and security fundamentals.

## Topics Learned
- Cybersecurity Fundamentals
- Networking Concepts
- Linux Basics
- Windows Basics
- Security Principles
- Threats and Risks
- Access Control
- Security Awareness

## Current Objectives
- Build foundational cybersecurity knowledge
- Prepare for ISC2 Certified in Cybersecurity (CC)
- Strengthen networking and Linux skills
- Develop a path toward SOC Analyst and Blue Team roles

## Key Skills Being Developed
- Technical documentation
- Networking fundamentals
- Security mindset
- Incident awareness
- Cybersecurity terminology

## Notes
This course is providing a strong introduction to cybersecurity concepts and practical foundational knowledge.
